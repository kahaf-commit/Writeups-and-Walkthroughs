**PIE=**
• **Permitted (`p`)**: **Allowed** power. Max permissions a program can ever use.
• **Effective (`e`)**: **Active** power. What the program is using right now.
• **Inheritable (`i`)**: **Passed** power. Permissions that child programs get.
