# Setup

```markup
1. Search Pivoting LAB On google
2. apt install docker.io
3. apt install docker-compose
4. git clone https://github.com/franc205/dvpe.git
5. cd pivoting-lab
6. sudo docker compose up -d --build
7. docker compose up -d
```
